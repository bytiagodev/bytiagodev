Drawing was something I enjoyed growing up. I lost touch with it for a long time but always felt like something creative was missing. Turns out, creating things for the web brings back that same feeling.

## Ideas made real

**[Bruce Investigates](https://bytiagodev.github.io/bruce-investigates/)**
*A pug, a missing treat, and a very serious investigation.*
A children's story about a real pug named Bruce, illustrated across 13 spreads in English and Portuguese.

**[Dusty Grooves](https://bytiagodev.github.io/dusty-grooves)**
*If it ain't vinyl, it ain't real.*
A 1983 vinyl record shop with a character who reacts to everything you do. Search for a song, pick a track, and the music plays.

**[Quiet Garden](https://bytiagodev.github.io/quiet-garden-landing-page/)**
*Built without a single photograph.*
A botanical store landing page made entirely with watercolour illustrations, blend modes and organic CSS shapes.
